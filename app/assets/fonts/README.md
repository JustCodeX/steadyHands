# Fonts

Both fonts are from Google Fonts and licensed under the SIL Open Font License 1.1 (the licence texts are next to the files).

| File | Used for |
| --- | --- |
| `LilitaOne-Regular.ttf` | Titles, numbers, labels |
| `VarelaRound-Regular.ttf` | Body text and hints |

If a file is missing the game falls back to pygame's default font (`trainer/ui/fonts.py`).
